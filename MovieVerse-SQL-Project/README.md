# 🎬 MovieVerse SQL Project

## 📌 Overview

This project contains solutions to **25 SQL practice questions** based on the **MovieVerse** database. The objective was to strengthen SQL skills by solving real-world business queries using PostgreSQL.

## 🛠️ Tech Stack

- PostgreSQL
- pgAdmin 4
- SQL

## 🗄️ Database Schema

The project uses the following tables:

- Movies
- Genres
- Movie_Genres
- Actors
- Movie_Actors
- Users
- Ratings

## 📚 SQL Concepts Covered

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- Subqueries
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- RANK()
- DENSE_RANK()
- ROW_NUMBER()
- LAG()

## 📋 Practice Questions Solved

- Retrieved movies based on release year and duration
- Filtered users based on country and rating activity
- Performed pattern matching using LIKE and ILIKE
- Worked with multiple table joins
- Solved many-to-many relationship queries
- Used aggregate functions for reporting
- Categorized users using CASE statements
- Implemented CTEs and Window Functions
- Ranked movies using RANK() and DENSE_RANK()
- Compared sequential ratings using LAG()
